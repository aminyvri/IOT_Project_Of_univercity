# 🎓 سیستم هوشمند حضور و غیاب مبتنی بر IoT (NFC + دوربین)

سیستم حضور و غیاب دانشگاهی/سازمانی که با **کارت NFC/RFID**، **ماژول ESP32**، **دوربین** و **پنل مدیریت تحت وب (Flask)** کار می‌کند. با هر بار اسکن کارت، ورود یا خروج فرد ثبت می‌شود، از او عکس گرفته می‌شود و ساعات کارکرد و حقوق به‌صورت خودکار محاسبه می‌گردد.

---

## ✨ امکانات

- 🪪 ثبت ورود/خروج با اسکن کارت NFC/RFID
- 📸 عکس‌برداری خودکار از دوربین در لحظه ورود و خروج
- 🙂 احراز هویت با تشخیص چهره (مرحلهٔ بعد از اسکن کارت)
- ⏱ محاسبهٔ خودکار مدت حضور در هر نوبت
- 💰 محاسبهٔ ساعات کارکرد کل و حقوق بر اساس نرخ ساعتی هر فرد
- 👥 ثبت و ویرایش کاربران (نام، کد پرسنلی، کد ملی، تاریخ تولد، نوع کاربر، نرخ ساعتی، عکس پروفایل)
- 📊 داشبورد آمار: تعداد کل، حاضر، غایب
- 📟 نمایش وضعیت (خوش‌آمد، خداحافظ، مدت کارکرد، خطا) روی نمایشگر OLED
- 🔄 API برای نمایش زندهٔ ۲۰ تردد آخر
- 🔐 ورود به پنل با رمز عبور و امکان تغییر رمز
- 🌐 نمایش IP محلی سرور برای اتصال آسان ESP32

## 🏗 معماری سیستم

```
┌──────────────┐   UID    ┌──────────────┐  HTTP POST   ┌────────────────────┐
│ کارت NFC/RFID│ ───────► │   ESP32    │ ───────────► │   سرور Flask       │
└──────────────┘          │ + ماژول NFC  │ /rfid_scan   │                    │
                          └──────────────┘ ◄─────────── │ • ثبت ورود/خروج    │
                                 ▲          JSON پاسخ   │ • عکس از دوربین    │
                                 │                      │ • تشخیص چهره       │
                       نمایش پیام روی OLED          │ • SQLite           │
                                                        └─────────┬──────────┘
                                                                  │
                                       ┌──────────────┐           ▼
                                       │ دوربین USB   │   ┌────────────────┐
                                       │ (OpenCV)     │   │ پنل مدیریت وب  │
                                       └──────────────┘   └────────────────┘
```

**جریان کار:**
1. کاربر کارت را اسکن می‌کند.
2. ESP32 UID کارت را به سرور می‌فرستد.
3. سرور از دوربین عکس می‌گیرد و هویت فرد را بررسی می‌کند.
4. اگر نوبت باز (ورود بدون خروج) وجود داشته باشد، **خروج** ثبت می‌شود؛ در غیر این صورت **ورود** جدید.
5. پاسخ (نام، وضعیت، مدت حضور) به ESP32 برگردانده می‌شود.

## 🔌 API

### `POST /rfid_scan`
ارسال UID کارت از ESP32.

**درخواست:**
```json
{ "uid": "A1B2C3D4" }
```

**پاسخ‌ها:**

| وضعیت | نمونه پاسخ |
|-------|-----------|
| ورود | `{"status":"Enter","name":"علی","msg_fa":"ورود موفق","dur":"-"}` |
| خروج | `{"status":"Exit","name":"علی","msg_fa":"خروج موفق","dur":"8:15:30"}` |
| کارت ناشناس | `{"status":"Unknown","name":"Unknown","msg_fa":"کارت ناشناس","dur":"-"}` |

### `GET /api/get_logs`
۲۰ تردد آخر به‌صورت JSON (نیازمند ورود به پنل نیست؛ در صورت نیاز محافظت شود).

### سایر مسیرها

| مسیر | متد | توضیح |
|------|-----|-------|
| `/` | GET | داشبورد مدیریت |
| `/login` | GET/POST | ورود مدیر |
| `/logout` | GET | خروج از پنل |
| `/change_pass` | POST | تغییر رمز مدیر |
| `/register_user` | POST | ثبت یا ویرایش کاربر |

## 📟 کد ESP32

کد کامل در `arduino/rfid_client/rfid_client.ino` قرار دارد.

**اتصال پین‌ها:**

| قطعه | پین |
|------|-----|
| RC522 – SDA (SS) | GPIO 5 |
| RC522 – RST | GPIO 4 |
| RC522 – SCK / MOSI / MISO | پین‌های پیش‌فرض SPI |
| OLED SSD1306 – SDA / SCL | پین‌های پیش‌فرض I2C (آدرس `0x3C`) |

**کتابخانه‌های لازم** (از Library Manager): `MFRC522`، `Adafruit GFX Library`، `Adafruit SSD1306`، `ArduinoJson`

**قبل از آپلود** این مقادیر را تنظیم کنید:
```cpp
const char* ssid = "WIFI_NAME";
const char* pass = "WIFI_PASSWORD";
String laptop_ip = "192.168.1.2";   // IP کامپیوتری که سرور روی آن اجراست
```

**رفتار نمایشگر:**

| وضعیت | پیام روی OLED |
|-------|---------------|
| آماده‌باش | `Waiting – Place Card Here...` |
| ورود | `Welcome` + نام |
| خروج | `Goodbye` ← تأیید خروج ← مدت کارکرد |
| کارت ناشناس | `Unknown Card – Contact Admin` |
| قطع بودن سرور | `Server Off – Check Python` |

> نمایشگر OLED فونت فارسی ندارد؛ پیام‌ها انگلیسی/فینگلیش نمایش داده می‌شوند.

## 🔐 نکات امنیتی

قبل از استفاده در محیط واقعی حتماً:

- مقدار `secret_key` و رمز پیش‌فرض (`admin_pass`) را از کد حذف کنید و از **متغیر محیطی** استفاده کنید.
- رمز عبور را به‌صورت **هش‌شده** نگه دارید (مثلاً `werkzeug.security`).
- مسیرهای `/api/get_logs`، `/change_pass` و `/register_user` را پشت بررسی `session` قرار دهید.
- مسیر `/rfid_scan` را با یک **توکن/کلید API** محافظت کنید.
- فایل دیتابیس و پوشهٔ عکس‌ها را در `.gitignore` قرار دهید (اطلاعات شخصی هستند).

نمونه `.gitignore`:
```
venv/
__pycache__/
*.db
static/photos/
```
